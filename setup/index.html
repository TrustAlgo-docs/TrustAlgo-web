SETUP GUIDEABOUT 10 MINUTES

Connect Hyperliquid.Keep your keys.

Hyperliquid does not issue a classic exchange API key. You connect your main wallet, deposit USDC into your Hyperliquid account, then authorize an API wallet. The API wallet can trade. It cannot withdraw.

01

Connect the master wallet

Open app.hyperliquid.xyz and connect MetaMask, Rabby, or WalletConnect. Sign the connection request. That signature identifies the account. It does not grant TrustAlgo, or the API wallet, withdrawal rights.

02

Deposit USDC to the exchange (1,000 USDC Recommended)

Connecting your wallet is not enough. You must actively transfer USDC from your personal wallet into your Hyperliquid L1 account using the "Deposit" button. While Hyperliquid credits deposits from 5 USDC, a minimum balance of 1,000 USDC is required for optimal position sizing across BTC, ETH, and SOL minimum lot constraints. Wait until the balance shows on Hyperliquid before creating the API wallet.

03

Open the API page

Go to More, then API, or open app.hyperliquid.xyz/API. An API wallet is an agent wallet: it signs for the master account. Info requests still use the master address, not the agent address.

04

Name it, then Generate

Enter a name (e.g., trustalgo). Ignore the 42-character address that auto-fills in the box. Click the green "Generate" text on the right. The screen will dim and a popup dialog will appear in the center.

05

Copy the 66-character Private Key

Inside that popup, you will see the actual Secret Private Key (64 or 66 characters). Copy this exact string immediately. Hyperliquid will never show it again once you close the window. After copying, click "Authorize API Wallet" to sign with your master wallet.

06

Submit and activate

Keep the master address and the API wallet private key separate. The master address is the account. The private key is the signer. Then submit both on the Get started form. You can revoke the API wallet on the Hyperliquid API page at any time.

Scope. The API wallet can place and manage orders. It cannot withdraw: withdrawals stay with your main wallet. If you lose the key, generate a new API wallet. Do not reuse a deregistered agent address.
