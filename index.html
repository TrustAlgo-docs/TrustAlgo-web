04 — SETUP

Connect a wallet. Create an API wallet.

Hyperliquid does not issue a classic exchange API key. You connect the master wallet, fund the account, then authorize an API wallet. The API wallet can sign trades. It cannot withdraw.

01

Connect the master wallet

Open app.hyperliquid.xyz and connect MetaMask, Rabby, or WalletConnect. Sign the connection request. That signature identifies the account. It does not grant TrustAlgo, or the API wallet, withdrawal rights.

02

Deposit collateral

Use Deposit in the app and send USDC on a network the deposit window lists. The minimum credited deposit is 5 USDC. Amounts below that are not credited. Wait until the balance shows on Hyperliquid before creating the API wallet.

03

Open the API page

Go to More, then API, or open app.hyperliquid.xyz/API. An API wallet is an agent wallet: it signs for the master account. Info requests still use the master address, not the agent address.

04

Name it, then generate

Enter a name, for example trustalgo. Click Generate. A named wallet is easier to track. An account can keep one unnamed API wallet and up to three named ones. Approving a new wallet with the same name replaces the previous one.

05

Copy the private key, then authorize

The dialog shows the private key once. Copy it into a password manager before you authorize. Then click Authorize API Wallet and sign with the master wallet. Default validity is 90 days. The maximum is 180 days. Hyperliquid will not show the key again.

06

Hand the key only to the node

Keep the master address and the API wallet private key separate. The master address is the account. The private key is the signer. Do not paste either into this page. Request a node, then deliver the key through the channel TrustAlgo gives you. You can revoke the API wallet on the same API page at any time.

Scope. The API wallet can place and manage orders. It cannot withdraw. Withdrawals stay on the master wallet. If the key is lost, generate a new API wallet. Do not reuse a deregistered agent address.
